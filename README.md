## Chat app

<p>This is a full stack Chat-App. Use Socket.io for realtime chatting and use mongoDB to store data</p>
<h2>Tech Stack</h2>

<ul>
  <li>Client: ReactJS, ChakraUI</li>
  <li>Server: ExpressJS, JWT,Cloudinary</li>
  <li>Database: MongoDB</li>
</ul>

## Run locally

<p>Clone the project</p>

```bash
  git clone https://github.com/cthanh2204/Chat-app.git
```
<p>Install on dependencies in both server and client</p>

```bash
  npm install
```

<p>Start the project in both server and client</p>

```bash
  npm run start
```
